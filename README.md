# Data Structures of a Blockchain

A field guide to the data structures blockchains actually run on — hash maps, hash-linked block lists, mempool queues, fee heaps, Merkle trees, the Merkle Patricia Trie, sparse Merkle trees, Bloom filters, LRU caches, append-only logs, and the P2P gossip graph — with diagrams for each mechanism and five build-it-yourself exercises with reference implementations.

Static single-page site, no build step. Open `index.html` directly or serve it as-is.
